# BluePawz Transmitter 🛰️

ESP32-based GPS LoRa transmitter for pet tracking.

## 📦 Components

- ESP32 (Seeeduino XIAO ESP32S3)
- GPS module (e.g. NEO-6M)
- SX1262 LoRa module
- 3.3V LiPo battery
- Antenna

## ⚙️ Features

- Sends GPS coordinates via LoRa to receiver
- Low-power standby modes (planned)
- LED status indication


## 🧪 Testing

- Connect to serial monitor (115200 baud)
- Check GPS lock and LoRa transmission status
